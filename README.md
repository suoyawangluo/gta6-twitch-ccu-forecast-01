Forecasts Grand Theft Auto VI's launch-day Twitch viewers hour by hour (hours 2–24 of 2026-11-19 UTC) as five quantiles an hour, from the first hour's print and the case's comparable launches. For every comparable launch it takes the log viewer-ratio curve against that launch's own first hour, then fits one small ridge regression per hour on the launch's first-hour size, how its last pre-midnight hour compared with its first hour, and whether it had an early-access head start. Launches whose first hour was still dead (a single simultaneous unlock later in the day) are left out. Quantiles come from the regression's residual spread, smoothed lightly across neighbouring hours. Pure standard library, no network, deterministic: the same case always yields the same bytes.
